## Ответы на контрольные вопросы:

1. **В чем разница между локальным репозиторием Git и удаленным репозиторием GitHub?**
   Локальный репозиторий — это скрытая папка `.git` на компьютере, где хранится вся 
история изменений. Удаленный репозиторий — это копия проекта на сервере (в данном случае на GitHub),
 которая используется для совместной работы, резервного копирования и демонстрации кода.

2. **За что отвечают команды `git add` и `git commit`? Какова последовательность их применения?**
   `git add` добавляет изменения из рабочего каталога в индекс (staging area) для подготовки к коммиту.
 `git commit` сохраняет эти проиндексированные изменения в локальной истории репозитория.
Последовательность: сначала `git add <файлы>` (или `git add .`), затем `git commit -m "Сообщение"`.

3. **Что делает команда `git push`?**
   Команда `git push` отправляет (загружает) локальные коммиты в удаленный репозиторий (например, на GitHub).

4. **Зачем нужна команда `git status`?**
   Команда `git status` показывает текущее состояние рабочего каталога и индекса: какие файлы были изменены,
 какие добавлены в индекс, а какие еще не отслеживаются Git.
