**Тема:** Основы работы с системой контроля версий Git и веб-сервисом GitHub

**Цель работы:**Изучить базовые концепции контроля версий, приобрести практические навыки установки и настройки Git, создания локальных и удаленных репозиториев, а также организации структуры для хранения последующих лабораторных работ по программированию.

**Теоретические сведения:**

- **Git** — это распределенная система контроля версий. Она позволяет фиксировать изменения в файлах (делать «снимки» проекта — коммиты), возвращаться к предыдущим версиям кода и безопасно вести разработку.
- **Локальный репозиторий** — скрытая папка .git на компьютере, где хранится вся история изменений проекта.
- **Удаленный репозиторий** — копия проекта, размещенная на сервере в сети (в данном случае на GitHub). Служит для резервного копирования и демонстрации кода.
- **Коммит (Commit)** — сохраненное состояние проекта с уникальным идентификатором. Каждое сохранение сопровождается осмысленным описанием выполненной работы.

**В ходе лабораторной работы я выполнил следующие шаги:**

1. **Установка и настройка Git:**\
   Я проверил версию Git командой git --version. Затем настроил глобальные параметры пользователя (свое имя и email), которые будут привязываться к каждому коммиту:\
   git config --global user.name "Вегнер Владислав"\
   git config --global user.email "vegnervlad10@gmail.com"
1. **Создание структуры локального репозитория:**\
   Я создал корневую папку programming-labs для хранения всех работ по дисциплине. В ней инициализировал Git-репозиторий командой git init. Внутри создал директорию для первой работы lab\_01 и файл main.py.
1. **Фиксация изменений (Первый коммит):**\
   Я проверил состояние репозитория командой git status (файлы отображались как неотслеживаемые — Untracked). Все созданные файлы я добавил в индекс командой git add . и зафиксировал первым коммитом:\
   git commit -m "Initial commit: create structure and lab\_01"
1. **Создание репозитория на GitHub:**\
   На сайте [github.com](https://github.com/) я создал новый публичный репозиторий с именем programming-labs. При создании отключил опции инициализации (Add a README, .gitignore, license), так как код уже существовал локально.
1. **Связывание и отправка кода:**\
   Я связал локальный репозиторий с удаленным с помощью команды git remote add origin. Ветку переименовал в main командой git branch -M main. Затем выполнил отправку файлов на сервер командой git push -u origin main.
1. **Создание отчета в формате Markdown:**\
   В соответствии с заданием, я оформил отчет в формате Markdown (файл README.md) и отправил его в репозиторий.
