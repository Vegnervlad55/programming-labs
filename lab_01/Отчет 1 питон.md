**Вариант №4:** Период колебаний пружинного маятника\
**Формула:** T = 2 · π · √(m / k)

m (масса) = 0.45 кг

k (жёсткость) = 150 Н/м

π = 3.14159

**Исходный код программы**

import math *\# Подключаем математический модуль*

print(\"Формула: T = 2 \* pi \* sqrt(m / k)\") *\# формула по условию
задачи*

pi = 3.14159 *\# ЧИСЛО ПИ*

m = float(input(\"Введите массу груза m (кг): \")) *\# МАСС по
условия(0.45)*

k = float(input(\"Введите жесткость пружины k (Н/м): \")) *\# ЖЕСТКОСТЬ
по условия(150)*

T = 2 \* pi \* math.sqrt(m / k) *\# Вычисление периода колебаний*

print(\"Результат (Период колебания пружинного маятника):\")

print(f\"Период колебаний: T = {T:.4f} с\") *\# вывод на экран
вычисления*

**Ход вычислений:**

1.  Вычисляем отношение массы к жёсткости:\
    m / k = 0.45 / 150 = 0.003

2.  Извлекаем квадратный корень:\
    √0.003 ≈ 0.05477

3.  Умножаем на 2π:\
    T = 2 · 3.14159 · 0.05477 ≈ 0.3441 с
