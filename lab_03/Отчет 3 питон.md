import sys

from variant4_mod import parse_frame, filter_known_slaves,
format_telemetry_dict

target = int(sys.argv\[1\]) if len(sys.argv) \> 1 else 5

frame = \[5, 3, 0, 100, 0, 2, 180, 22\]

allowed = {1, 3, 5, 12}

dev_id, func, data = parse_frame(frame)

ok = filter_known_slaves(dev_id, allowed)

print(f\"Доступ: {\'да\' if ok else \'нет\'}\")

**Вывод**

В ходе выполнения лабораторной работы №3 были изучены принципы
модульного программирования в Python и освоены базовые структуры данных.

В результате работы:

1.  Был создан пользовательский модуль variant4_mod.py, содержащий три
    функции с docstrings и блок автономного тестирования if \_\_name\_\_
    == \'\_\_main\_\_\':.

2.  Был разработан главный исполняемый скрипт main.py, который
    импортирует функции из модуля через from variant4_mod import \... и
    использует системный модуль sys для чтения аргументов командной
    строки.

3.  Продемонстрирована работа с **кортежами** (функция parse_frame
    возвращает кортеж из трёх значений, который распаковывается в
    переменные dev_id, func, data).

4.  Продемонстрирована работа со **срезами** --- срез frame\[2:-2\]
    позволяет извлечь полезную нагрузку кадра, отбросив первые два байта
    (адрес и код функции) и последние два байта (CRC).

5.  Продемонстрирована работа с **множествами** --- проверка slave_id in
    allowed_set реализует быструю фильтрацию адресов устройств.

6.  Продемонстрирована работа со **словарями** --- функция
    format_telemetry_dict формирует сводный словарь телеметрии из ID
    устройства и словаря регистров.

7.  Освоен механизм чтения аргументов командной строки через sys.argv с
    использованием fallback-значения (sys.argv\[1\] if len(sys.argv) \>
    1 else 5), что позволяет запускать скрипт как с параметром, так и
    без него.

8.  Проверена работа блока if \_\_name\_\_ == \'\_\_main\_\_\': --- при
    запуске модуля напрямую выполняется автотест, а при импорте в
    main.py он не мешает основной программе.
