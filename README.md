## Контрольные вопросы

### 1. В чём разница между локальным репозиторием Git и удалённым репозиторием GitHub?
Локальный репозиторий — это скрытая папка `.git` на компьютере, где хранится вся история изменений проекта. Работать с ним можно без интернета. Удалённый репозиторий (GitHub) — копия проекта на сервере в сети; он нужен для резервного копирования, совместной работы и демонстрации кода (например, преподавателю).

### 2. За что отвечают команды git add и git commit? Какова последовательность применения?
`git add` добавляет изменения файлов в индекс (staging area) — подготавливает их к фиксации. `git commit` сохраняет подготовленные изменения в историю репозитория с уникальным идентификатором и сообщением. Последовательность: сначала `git add .` (или `git add <файл>`), затем `git commit -m "описание"`.

### 3. Что делает команда git push?
Отправляет локальные коммиты в удалённый репозиторий (на GitHub). При первом push используется `git push -u origin main` — флаг `-u` связывает локальную ветку `main` с удалённой, чтобы дальше можно было писать просто `git push`.

### 4. Зачем нужна команда git status?
Показывает текущее состояние рабочей директории и индекса: какие файлы изменены, какие подготовлены к коммиту (`staged`), какие не отслеживаются (`untracked`), на какой ветке находишься. Помогает контролировать, что именно попадёт в следующий коммит.
